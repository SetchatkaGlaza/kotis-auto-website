# Публикация на GitHub Pages

Всё делается в браузере, терминал не нужен.

## Один раз

1. Создайте репозиторий на GitHub (Public или Private; для бесплатных Pages на личном аккаунте репозиторий должен быть **Public**).
2. Нажмите **Add file → Upload files** и перетащите всё **содержимое** папки `kotis-site` (не саму папку).
   Папка `.github` с вложенными файлами скрыта в проводнике Windows/macOS. Если она не загрузилась, создайте файл вручную:
   **Add file → Create new file**, имя `.github/workflows/pages.yml`, вставьте содержимое из архива.
3. Нажмите **Commit changes**.
4. Откройте **Settings → Pages**. В поле **Source** выберите **GitHub Actions**.
5. Откройте вкладку **Actions**: запустится «Публикация сайта». Через 1–2 минуты зелёная галочка означает, что сайт опубликован.
   Адрес будет вида `https://ваш-логин.github.io/название-репозитория/`.

Дальше сайт обновляется сам при каждом изменении файлов в ветке `main`.

## Свой домен

1. В **Settings → Pages → Custom domain** впишите домен и сохраните.
2. У регистратора домена создайте нужные DNS-записи (GitHub показывает их на той же странице).
3. В **Settings → Secrets and variables → Actions → Variables** создайте переменную `SITE_URL` со значением `https://ваш-домен.ru`,
   чтобы canonical, карта сайта и картинка для соцсетей указывали на домен.

## Что делает автоматическая публикация

1. Берёт нужные файлы (без `tools/`, `docs/` и служебных).
2. Подставляет адрес сайта вместо `__SITE_URL__` в `index.html`, `robots.txt` и `sitemap.xml`.
3. Публикует результат.

Если в журнале Actions красный крестик, откройте запись и прочитайте последнюю строку: чаще всего Pages ещё не включены (шаг 4).

## После публикации

- Откройте сайт с телефона и с компьютера, проверьте форму, карту и звонок по кнопке.
- Добавьте адрес сайта в Яндекс Вебмастер и укажите `https://адрес/sitemap.xml`.
- Проверьте картинку для соцсетей: она лежит в `assets/img/brand/og-image.jpg`.
