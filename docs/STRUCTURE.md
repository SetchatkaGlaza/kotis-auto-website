# Структура проекта

Сайт статический: ничего устанавливать и собирать не нужно.

## Корень

| Файл | Назначение |
|---|---|
| `index.html` | Вся страница: разметка, тексты, цены, отзывы, вопросы |
| `404.html` | Страница «не найдено» (стили внутри файла) |
| `site.webmanifest` | Название, цвета и иконки сайта для браузеров |
| `robots.txt`, `sitemap.xml` | Подсказки для поисковиков |
| `.nojekyll` | Просит GitHub Pages отдавать файлы как есть |
| `.github/workflows/pages.yml` | Автоматическая публикация |
| `PROGRESS.md` | Журнал работы и принятых решений |

В `index.html`, `robots.txt` и `sitemap.xml` встречается `__SITE_URL__`. Это заглушка: при публикации
рабочий процесс сам подставляет адрес сайта. Руками её менять не нужно.

## assets/css

| Файл | Что в нём |
|---|---|
| `tokens.css` | Шрифты, цвета тёмной и светлой тем, отступы, скругления, скорости анимаций |
| `main.css` | Основные стили: кнопки, шапка, меню, hero, окна, форма, подвал, адаптив |
| `motion.css` | Анимации и стили «живых» блоков: появление, hero, услуги, вкладки, отзывы, вопросы |

`motion.css` подключается после `main.css` и при необходимости переопределяет его правила.

## assets/js

| Файл | Что делает |
|---|---|
| `config.js` | **Настройки для владельца**: телефон, ссылка ВК, куда слать заявки, какие фото на странице |
| `gallery-data.js` | Список фото галереи с подписями (создаётся скриптом `tools/build_assets.py`, руками не править) |
| `core.js` | Тема, шапка, мобильное меню, кнопка «наверх», карта |
| `motion.js` | Анимации: появление, hero, счётчик, вкладки, карусель услуг, плавные вопросы |
| `gallery.js` | Фото на странице, окно «Все работы», просмотр |
| `calculator.js` | Калькулятор (читает цены из карточек услуг) |
| `reviews.js` | Бегущая лента отзывов |
| `form.js` | Форма записи, маска телефона, отправка |

Скрипты обычные (не модули), поэтому сайт открывается и двойным кликом.

## assets/img

| Папка | Содержимое |
|---|---|
| `brand/` | Логотип, иконки, картинка для соцсетей (`og-image.jpg`), логотипы студии |
| `hero/` | Кадры главного экрана и карточек услуг |
| `gallery/thumb`, `gallery/full` | Превью и крупные версии 73 фото работ |
| `dev/` | Логотип студии-разработчика |

## tools

Нужны только если вы заменяете фото или шрифты (требуется Python и библиотека Pillow). Для обычной работы сайта не нужны.

| Скрипт | Назначение |
|---|---|
| `build_assets.py` | Готовит галерею, кадры, логотипы из исходных фото |
| `optimize_images.py` | Сжимает изображения |
| `subset_fonts.py` | Делает лёгкие шрифты (кириллица + латиница) |

## Цвета

Основной цвет сайта (янтарный) и тёмные/светлые оттенки лежат в `assets/css/tokens.css`. Поменяйте значение
`--amber`, и кнопки, акценты и анимации перекрасятся сразу.
