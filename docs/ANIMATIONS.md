# Анимации: что за что отвечает

Принцип: двигаем только `transform`, `translate` и `opacity`. Без размытия и анимации фильтров, чтобы было плавно и на телефонах.

## Как это устроено

- `assets/css/motion.css` описывает, **как** выглядит движение.
- `assets/js/motion.js` решает, **когда** оно запускается (при прокрутке, наведении, нажатии).
- Скорости и «мягкость» берутся из `tokens.css` (`--ease`, `--t`, `--t-fast`).

## Как добавить появление любому блоку

Добавьте блоку класс `reveal`. Чтобы несколько соседних блоков появлялись по очереди, задайте номер:

```html
<div class="why-item reveal" style="--i:2">…</div>
```

| Эффект | Класс / место | Где менять |
|---|---|---|
| Полоса прокрутки сверху | `.scroll-progress` | `motion.css`, `motion.js` |
| Появление блоков | `.reveal` | `motion.css` (ключ `reveal-in`) |
| Заголовок по словам | `.hero h1 .w` | `motion.js` (`hero`) |
| Фото справа в главном блоке | `.hero-visual`, `.hero-layer`, `.hero-stitch`, `.hero-tags` | `motion.css` |
| Блик под курсором | `.spot` | `motion.css`, `motion.js` (`pointerFx`) |
| «Притяжение» крупных кнопок | `.btn-primary.btn-lg` | `motion.js` (`pointerFx`) |

## Как сделать спокойнее

- Главный блок слишком живой: в `motion.css` удалите строки с `.hero-tags` (метки) или увеличьте время в `@keyframes kenburns` (по умолчанию 24 секунды).
- Не нужен «блик» на кнопках: удалите правила `.btn-primary::after` и `.btn-primary:hover::after`.
- Отключить анимацию появления везде: уберите подключение `motion.js` из `index.html` (блоки останутся видимыми благодаря страховке).

## Режим «уменьшить анимацию»

Если в системе включено «уменьшить движение», сайт показывает все блоки сразу, не двигает отзывы (их можно листать вручную) и отключает бегущие эффекты.
Это настройка посетителя, отдельно её включать не нужно.
