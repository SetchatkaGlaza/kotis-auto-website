# Журнал работы над проектом

Проект делается поэтапно; после каждого этапа выдаётся архив. Если работа
прервётся — достаточно этого файла и архива, чтобы продолжить без повторения.

## Решения по проекту
- Сайт: статический (HTML + CSS + JS без сборки), деплой на GitHub Pages.
- Скрипты подключаются обычными `<script defer>` (не ES-модули), чтобы сайт
  открывался и двойным кликом по `index.html`.
- Шрифты: Inter / Inter Display, подмножество (латиница + кириллица), WOFF, лежат в `assets/fonts`.
- Цены на карточках услуг — единый источник правды: `data-price` в HTML, калькулятор читает их оттуда.
- Две темы (тёмная по умолчанию + светлая); в подвале логотип студии SetchatkaGlaza
  меняется под тему и ведёт на https://setchatkaglaza.github.io/setchatkaglaza/
- Коммиты в git не создаются без прямого разрешения владельца.

- Скрипт `tools/build_assets.py`: вызов `split_compare` закомментирован (до/после убрано). Папки `img/ba` и `img/compare` удалены из сайта.

## Этап 3 (анимации и переработка блоков), часть 1 — сделано
- Новые файлы: `assets/css/motion.css` (анимации и стили новых блоков), `assets/js/motion.js` (скрипты анимаций).
- Общее: полоса прокрутки сверху, плавное появление блоков (`.reveal`, есть страховка, если скрипт не сработал),
  чёрточка под заголовками разделов, блеск на кнопках, на телефоне шапка прячется при прокрутке вниз.
- Главный блок: заголовок появляется по словам; справа медленное движение фото, бегущая «строчка» вокруг, блик,
  три плавающие метки, лёгкое смещение за мышью (ПК) и при прокрутке. Метки: «Алькантара», «Кожа», «Строчка ромбом».
- Услуги: бейдж цены на фото, теги, стрелка, блик под курсором; список с номерами и анимацией линии;
  блок «Не нашли свою задачу» (ВК и звонок); на телефоне три главные карточки листаются пальцем с точками.
- «Комфорт, тишина, стиль»: три вкладки с анимацией (фото / волна «шум → тишина» / фото и образцы цветов) + мозаика «почему мы»
  с числом «10 лет», которое набегает. Тексты вкладок собраны из уже имевшихся описаний, новых фактов нет.
- Окно «Все работы»: высота через dvh (не срезается адресной строкой телефона), фильтры на ПК переносятся на строки,
  на телефоне прокручиваются с затуханием по краям и подкатывают выбранный; плавное открытие/закрытие; счётчик фото.
- Просмотр фото: перестроен (счётчик, кнопки внизу на телефоне, не перекрывают фото, анимация листания).
- Не проверено: реальные телефоны (проверено только эмулятором Chromium), Safari/Firefox, плавность на слабых устройствах.

## Этап 3, часть 2 — сделано
- «Как мы работаем»: шаги соединены «нитью», которая прорисовывается при прокрутке (на телефоне вертикально), кнопки «Записаться / Позвонить».

- Частые вопросы: плавное раскрытие по высоте, янтарная линия слева у открытого, значок «+» превращается в «−».
- Запись и контакты: плавные наведения, всплывающие способы оплаты, анимация результата отправки формы.
- Общее: плавная смена светлой/тёмной темы, «прыжок» суммы в калькуляторе, анимация галочек.
- Проверено в Chromium (эмуляция): ширины 320, 390, 768, 1280, 1920 — без горизонтального переполнения, консоль без ошибок,
  режим «уменьшить анимацию» показывает всё сразу.
- Не проверено: карта Яндекса (нет интернета в среде), реальные телефоны, Safari и Firefox, нагрузка на слабых устройствах.
